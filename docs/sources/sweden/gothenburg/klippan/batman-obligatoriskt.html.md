# Båtmän

Båtmän vid förtöjning i Göteborgs hamn.

## Båtmän obligatoriskt

Det är obligatoriskt att använda utbildade båtmän vid förtöjning i Göteborgs hamn. Detta gäller för samtliga fartyg i Energihamnen och fartyg med LOA om 80 meter eller mer i övriga delar av Göteborgs hamn. Beställning av båtmän görs via VTS Göteborg på VHF kanal 13.

Se även: Klippans båtmansstation (telefon +46-31-14 46 77)
